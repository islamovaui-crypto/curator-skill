# Помощник куратора — скилл для Claude Code

Скилл помогает кураторам учебных чатов писать сообщения, на которые отвечают: приветствие новичку, ответ на вопрос, отклик на результат, утреннее сообщение, итоги недели, пост в канал. Переписывает слабые тексты по схеме «было → стало» и проверяет чат по чек-листу.

Методика собрана на разборе чатов школы за май–сентябрь 2026 года: 4 795 сообщений в командных чатах, 23 больших чата, 1 638 постов в каналах.

## Установка

Скопируйте папку `curator-assistant` в папку скиллов:

```bash
git clone https://github.com/islamovaui-crypto/curator-skill.git
mkdir -p ~/.claude/skills
cp -r curator-skill/curator-assistant ~/.claude/skills/
```

Скилл подключится со следующего сообщения.

## Как пользоваться

Просто напишите агенту, например:

- «Напиши приветствие новичку: Татьяна, бухгалтер из Самары, хочет разобраться с отчётами»
- «Как ответить: Олег подсказал Ирине решение, оно верное»
- «Поправь пост: Вышел новый урок! Смотрите на платформе»
- «Напиши итоги недели: Анна собрала бота, Сергей подключил Telegram, Олег помогал с доступами»
- «В чате тихо два дня, что написать?»

## Состав

- `curator-assistant/SKILL.md` — правила и типовые задачи
- `curator-assistant/references/examples.md` — примеры «было → стало» и готовые тексты на неделю
- `curator-assistant/references/checklist.md` — чек-лист на день и неделю, четыре цифры
